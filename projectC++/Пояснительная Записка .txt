Пояснительная записка к проекту "Менеджер паролей"

Студент:[Бойко Артём]  
Дисциплина: ООП с использованием с++

1. Обоснование полезности

Проблема: Современный человек имеет 10-20 аккаунтов. Запомнить все пароли невозможно. Хранение в блокноте или Excel небезопасно и неудобно.

Пользователи:Студенты, семьи, все кто хочет безопасно хранить пароли.

**Преимущества перед Excel:**
- Шифрование паролей
- Генерация надёжных паролей
- Оценка сложности
- Поиск и сортировка
- Автосохранение

2. Описание предметной области

Классы:

| Класс | Описание |
|-------|----------|
| BaseEntity | Базовый абстрактный класс |
| SocialPassword | Пароль для соцсетей |
| BankPassword | Пароль для банков |
| Repository | Хранилище объектов |
| Stack | Стек для отмены действий |

Связи:
- SocialPassword и BankPassword наследуются от BaseEntity
- Repository хранит (агрегирует) BaseEntity
- Stack содержит vector (композиция)

Сценарии:
1. Добавить пароль → ввод данных → шифрование → сохранение
2. Посмотреть пароли → расшифровка → вывод на экран
3. Поиск по названию → фильтрация → вывод результатов
