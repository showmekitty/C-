Менеджер паролей

Консольное приложение для безопасного хранения паролей с шифрованием.


Описание

Программа позволяет хранить пароли от социальных сетей и банковских карт в зашифрованном виде.

Возможности

- Добавление паролей (соцсети / банки)
- Просмотр всех паролей
- Редактирование и удаление по ID
- Поиск по названию сервиса
- Сортировка по алфавиту
- Генерация случайных паролей
- Оценка сложности пароля
- Сохранение и загрузка из файла


Компиляция и запуск

Visual Studio

1. Открыть `ProjectC++.sln`
2. Нажать `Ctrl + Shift + B` (сборка)
3. Нажать `Ctrl + F5` (запуск)
